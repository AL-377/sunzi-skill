# 决策模型分析

## 孙子兵法中的决策框架提炼

---

## 模型一：始计决策模型（五事七计）

### 原理
"夫未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也。多算胜，少算不胜，而况于无算乎！"

### 框架

**五事评估**：

```
道 → 这件事的意义和支持度——关键利益方是否认同？
天 → 时机——外部趋势是否有利？
地 → 条件——资源和环境是否支持？
将 → 能力——执行者是否胜任？
法 → 体系——方法和制度是否完善？
```

**七计对比**（与竞争对手/对比选项）：

```
1. 主孰有道 → 谁的理念更得人心？
2. 将孰有能 → 谁的执行力更强？
3. 天地孰得 → 谁的时机条件更好？
4. 法令孰行 → 谁的组织更有效？
5. 兵众孰强 → 谁的资源更雄厚？
6. 士卒孰练 → 谁的团队更成熟？
7. 赏罚孰明 → 谁的激励更到位？
```

### 应用模板

**重大决策检查清单**：

| 维度 | 问题 | 你的答案 | 评分(1-5) |
|------|------|---------|-----------|
| 道 | 做这件事的意义清楚吗？关键人支持吗？ | | |
| 天 | 时机对吗？外部环境有利吗？ | | |
| 地 | 条件够吗？资源到位吗？ | | |
| 将 | 我/我的团队能力够吗？ | | |
| 法 | 方法清楚吗？有可行的计划吗？ | | |

**决策规则**：
- 5项均≥3：可以行动
- 3-4项≥3：需要补强薄弱项后行动
- ≤2项≥3：暂缓，条件不成熟

## 模型二：四层策略模型（伐谋-伐交-伐兵-攻城）

### 原理
"上兵伐谋，其次伐交，其次伐兵，其下攻城。"

### 框架

```
第一层（伐谋）：用智慧解决——不产生对抗
    ↓ 如果不行
第二层（伐交）：借第三方力量——间接解决
    ↓ 如果不行
第三层（伐兵）：正面沟通/交锋——有准备地面对
    ↓ 如果不行
第四层（攻城）：硬碰硬——最后手段
```

### 应用模板

遇到冲突/问题时，按顺序评估：

| 层次 | 问题 | 可行方案 | 代价评估 |
|------|------|---------|---------|
| 伐谋 | 能不能不对抗就解决？ | | 最低 |
| 伐交 | 能不能借力/找中间人？ | | 较低 |
| 伐兵 | 正面沟通能解决吗？ | | 中等 |
| 攻城 | 必须硬碰硬吗？ | | 最高 |

**决策规则**：能用上层就不用下层。

## 模型三：虚实分析模型

### 原理
"水之形，避高而趋下；兵之形，避实而击虚。"

### 框架

```
第一步：列出对方的"实"（强点、壁垒、底线）
第二步：列出对方的"虚"（弱点、盲区、需求）
第三步：列出自己的"实"（优势、资源、特长）
第四步：列出自己的"虚"（短板、缺陷、风险）
第五步：匹配——把"我的实"对准"对方的虚"
```

### 应用模板

| | 实（强点） | 虚（弱点） |
|---|-----------|-----------|
| **对方** | ① | ② |
| **自己** | ③ | ④ |

**策略矩阵**：
- **③ → ②**：核心策略——用我的优势打对方的弱点
- **保护 ④**：不让对方攻击我的弱点
- **避开 ①**：不在对方最强的地方硬拼
- **强化 ③**：持续放大自己的优势

## 模型四：上中下三策模型

### 原理
综合"伐谋/伐交/伐兵"和"风险-收益"两个维度

### 框架

| 策略 | 特征 | 风险 | 收益 | 条件要求 |
|------|------|------|------|---------|
| 上策 | 最优解，代价最小 | 低 | 高 | 需要更多条件/时间/智慧 |
| 中策 | 稳妥解，可操作 | 中 | 中 | 条件适中，可立即执行 |
| 下策 | 直接解，代价大 | 高 | 不定 | 条件最低，但风险最高 |

### 应用规则
1. 先评估是否具备执行上策的条件
2. 如果条件不足，退而求其次选中策
3. 下策是"不得已"——只在没有选择时使用
4. 将军自择——最终选择取决于你的具体处境和风险承受度

## 模型五：时机判断模型（势与节）

### 原理
"善战者，求之于势，不责于人。故能择人而任势。"

### 框架

**势的评估**：

```
上升势 → 顺势而为，加大投入
平势   → 蓄力等待，不轻举妄动
下降势 → 收缩防守，保存实力
```

**节的判断**：

```
时机成熟的信号：
- 外部环境出现有利变化
- 对方出现破绽/失误
- 自己准备充分
- 多个有利条件同时出现

时机未到的信号：
- 自己还没准备好
- 外部条件不支持
- 对方防守严密
- 风险大于收益
```

### 应用规则

| 势 | 节到 | 节未到 |
|----|------|--------|
| **上升势** | 全力出击 | 蓄力，但保持高度准备 |
| **平势** | 果断出手 | 继续等待 |
| **下降势** | 把握最后窗口 | 战略收缩，保存实力 |

## 模型六：情绪-决策防火墙

### 原理
"主不可以怒而兴师，将不可以愠而致战。合于利而动，不合于利而止。"

### 框架

**决策前的三问**：

```
1. 我现在情绪稳定吗？
   → 不稳定 → 停，冷静后再说
   → 稳定 → 继续

2. 这个决定符合我的长期利益吗？
   → 不符合 → 停，这可能是情绪驱动的
   → 符合 → 继续

3. 这个决定可逆吗？
   → 不可逆 → 再想三天
   → 可逆 → 可以尝试
```

**不可逆决策清单**（需要特别慎重）：
- 辞职
- 分手/离婚
- 绝交
- 大额投资
- 公开声明
- 法律行动

### 应用规则
- "怒而兴师"的决定，90%会后悔
- 重大决定至少"冷却"24小时
- 情绪激动时只做一件事：什么都不做
